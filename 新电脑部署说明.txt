智能宿舍管理系统 - 新电脑部署说明

环境要求：Java 17、Node.js 24、MySQL 8、Git。

1. 克隆 GitHub 仓库。
2. 创建 MySQL 数据库 alone。
3. 复制 backend/config/application-local.example.properties 为 application-local.properties，并填写本机数据库密码。
4. 在 backend 目录运行 .\mvnw.cmd spring-boot:run。
5. 在 frontend 目录运行 npm ci 和 npm run dev。
6. 浏览器访问 http://localhost:5173。

空数据库的首个管理员需要通过环境变量创建，项目不会提供公开的默认管理员密码。详细步骤见 README.md。
